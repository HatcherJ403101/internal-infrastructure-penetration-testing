# Assessment Evidence

This directory contains curated evidence supporting the investigations documented in this repository.

## Evidence Handling

Evidence is organised by investigation number and referenced from the corresponding investigation reports.

Before publication, evidence is reviewed to ensure it supports the documented finding while excluding unnecessary sensitive information.

- Remove credentials, session cookies, tokens, and other authentication material.
- Exclude private keys, personal information, and unrelated host details.
- Remove unnecessary MAC addresses, service fingerprints, and verbose scan metadata.
- Prefer concise summaries and cropped screenshots over unreviewed raw output.
- Include only evidence relevant to the investigation and its conclusions.

## Lab Scope

All testing relates to an authorised, isolated VirtualBox training environment using an intentionally vulnerable target.

Private lab addresses may appear where necessary to explain a finding. They should be clearly labelled as lab-only addresses.

## Evidence Integrity

Reports distinguish confirmed observations from potential impact and untested assumptions. Evidence should not be altered in a way that changes the meaning of the original result.
